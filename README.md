# Zoho-IgniteSparkz-Healthcare
A Zoho SalesIQ Codeless Healthcare Bot. IgniteSparkz Healthcare is a 24x7 healthcare chatbot built using Zoho SalesIQ Codeless Bot Builder. It provides automated symptom guidance, appointment support, and health tips, helping hospitals and clinics deliver quick, reliable assistance without any coding.

Live Bot Link:https://ignitesparkz.zohosites.com/

Features:
Book Appointments – Schedule appointments with healthcare providers quickly.
My Appointments – View and manage your upcoming or past appointments.
Our Services – Explore the healthcare services offered.
Contact or Help – Get instant assistance or contact support anytime.
24x7 Healthcare Assistance – Round-the-clock automated support.
FAQ Handling – Quick answers to common health-related queries.
User-Friendly Chat Interface – Easy and intuitive interaction for all users.

Bot Flow:
User → Bot Trigger → Conditions → Action → Response → End

User initiates chat
Bot checks the query or intent
Executes appropriate action (e.g., book appointment, show services, answer FAQs)
Bot responds with the result

Use Cases:
Hospitals & Clinics
Telemedicine platforms
Online healthcare portals
Customer support in healthcare
